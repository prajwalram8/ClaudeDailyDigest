# Daily Pulse feedback log

A record of missed items reported for the DP World Daily Pulse, and what was changed in
`.claude/skills/daily-pulse/SKILL.md` in response. Maintained by the `daily-pulse-feedback`
skill — see that file for how entries get added.

The point of this log is the audit trail, not the fix itself: the actual improvement always
lands as an edit to the daily-pulse skill (a new/adjusted search query, a materiality-bar
clarification, a source worth checking directly). If an entry says "no fix" that's a real
outcome — not every miss is systematic.
