# Daily Pulse archive

One file per run, named `YYYY-MM-DD.md`. Generated by the `daily-pulse` skill
(`.claude/skills/daily-pulse/SKILL.md`), either on demand or via the daily scheduled trigger.

Each run is a radar pass, not a digest: it flags only genuinely new, material developments
since the previous file in this folder, and stays silent on anything routine. Deeper themed
synthesis lives in the separate weekly digest, not here.
